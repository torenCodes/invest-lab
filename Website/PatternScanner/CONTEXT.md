# PatternScanner — Context & Architecture

**Dashboard:** Pattern Scanner
**URL:** https://invest-patterns.onrender.com
**Status:** Live (March 2026)

---

## Overview

Daily technical pattern scanner for all S&P 500 stocks (~503 tickers). Detects 6 classic chart patterns, grades each setup (A/B/Watch), and cross-references signals from other Invest Lab dashboards (Insider Buying, Tried & True ETF consensus).

Part of The Invest Lab — a personal stock research platform at theinvestlab.com.

---

## Architecture

| Component | Detail |
|-----------|--------|
| **Serving model** | Static Site on Render — same pattern as all non-Analyst dashboards |
| **Scan engine** | `scan.py` — Python + pandas + yfinance |
| **Frontend** | `index.html` — single-file HTML/CSS/JS dashboard |
| **Data** | `data/results.json` — generated by scan, served statically |
| **Workflow** | `.github/workflows/pattern-scanner.yml` — weekdays 9:40am ET (`40 13 * * 1-5`) |
| **Local dev** | `app.py` — minimal Flask file server (not used in production) |

### Data Flow

```
GitHub Actions (cron) → scan.py → data/results.json → git commit + push → Render serves static files
                                                                        → Homepage fetches top setup
```

## Universe & Data Sources

- **Tickers:** S&P 500 list scraped from Wikipedia (includes names + GICS sector for free)
- **Price data:** 1 year daily OHLCV via yfinance batch download
- **Cross-references:**
  - `InsiderBuying/data/results.json` — recent open-market insider purchases (+15 pts if match)
  - `TriedAndTrue/data/results.json` — ETF consensus top holdings (+10 pts if match)

## Patterns Detected

| Pattern | Key | Score Bonus | Detection Logic |
|---------|-----|-------------|-----------------|
| Bull Flag | `bull_flag` | +25 max | Flagpole 12%+ gain, tight flag <20% depth |
| VCP | `vcp` | +15 | 3 tightening 15-day windows, declining volume |
| BB Squeeze | `bb_squeeze` | +12 | Bollinger Band width at 6-month low |
| MA Crossover | `ma_crossover` | +10 | EMA 20 crossed above EMA 50 within 5 days |
| Cup & Handle | `cup_handle` | +18 | Within 15% of 52w high, rounded base + shallow handle |
| High-Vol Gap | `hv_gap` | +20 | 5%+ gap up on 2.5x average volume (last 20 days) |

---

## Grading System

**Base score** for any detected pattern: 30 pts
**Plus** pattern bonus (table above)
**Plus** indicator bonuses:

| Indicator | Bonus |
|-----------|-------|
| Above 200-day EMA | +10 |
| RS percentile ≥70% of 52w range | +10 |
| RS percentile ≥50% of 52w range | +5 |
| RSI between 45–70 (healthy) | +5 |
| Rising volume trend | +5 |
| Insider buying match | +15 |
| ETF consensus match | +10 |

**Thresholds:**
- **Grade A:** ≥65 pts — High-confidence setup with multiple confirming signals
- **Grade B:** ≥45 pts — Solid setup, worth monitoring for entry
- **Watch:** ≥30 pts — Early-stage pattern forming, not yet confirmed
- Below 30: excluded from output

## Dashboard UI

**Layout:** Sidebar (left) + Main content (right) — standard Invest Lab dashboard pattern

**Sidebar:** Title → scan status pulse → grade filter nav (All / A / B / Watch) with Grade A count badge → scan info stats → pattern list → disclaimer

**Main content:** Setup cards grid → glossary/explainer section

**Card anatomy:**
- Grade badge (A=green, B=teal, Watch=orange) + pattern pill + cross-ref badges (Insider, ETF)
- Ticker, company name, sector
- Price + today's change %
- Top 3 signals + "View Chart →" link (TradingView)
- Click to expand: score, RS percentile, week change, pattern details, all signals

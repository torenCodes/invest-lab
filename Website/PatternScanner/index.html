How to read this dashboard
Two complementary swing lists, both built from daily price structure across the broad liquid US market — no news, no hype, just the tape. Coiled surfaces tight setups before they go; Leaders surfaces the strongest names that still offer a sensible entry. A name can earn a place on both.
Coil Score (0–100) — Trend stack (30) + relative strength (25) + range tightness (25) + volume dry-up (20). Higher = more wound-up.
Leader Score (0–100) — Relative strength (50) + trend (25) + constructive setup (25). Rewards strength that hasn't yet run; gates out anything parabolic, broken, or already breaking out.
Pattern Tags
Volatility squeeze — Range has compressed to a tight band (<6%), the classic pre-breakout coil.
Tight base (VCP) — Volatility Contraction Pattern: range narrowing vs the prior base as supply dries up.
Bull flag — A strong run (the pole) digesting in a tight, calm consolidation (the flag).
Coiled base — An uptrending name basing constructively, building the next leg.
Metric Terms
RS %ile — Relative strength: 3-month return ranked against the whole universe. 90+ = top decile.
10-day range — Width of the recent consolidation as a % of price. Tighter = more coiled.
Vol vs base — Recent 10-day volume against its 50-day average. Below 100% = volume drying up.
vs 20-day — How far price sits above (or below) its 20-day average. Near zero = entry in range, not extended.

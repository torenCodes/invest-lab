# The Underdogs — Project Context

A dashboard that identifies high-quality companies with temporarily beaten-up stock prices.
Scans quality ETFs for stocks that score well on fundamentals but have been sold off.

**Not financial advice — educational/personal use only.**

---

## Architecture

```
scan.py  (standalone scanner)
 ├── Runs once, writes data/results.json, then exits
 ├── Invoked by GitHub Actions weekly (Mondays 9am ET)
 └── Can also be run manually: python scan.py

app.py  (minimal static file server)
 ├── GET /        → serves index.html
 ├── GET /ping    → health check
 └── GET /images/ → proxies images from Website/images/

index.html  (frontend)
 └── Fetches scan data client-side from data/results.json
```

**Run server:** `python app.py` → `http://localhost:8100`
**Run scan:** `python scan.py`

## Scoring System

### Composite Score
```
composite = quality_score × 0.45 + beaten_up_score × 0.40 + recovery_bonus
```
- `recovery_bonus` is capped at 30 points
- Minimum thresholds: `quality_score >= 30` AND `beaten_up_score >= 20`

### Quality Score (0–100)

**Standard path (non-financial sectors):**
| Signal | Points |
|--------|--------|
| Gross margin ≥ 60% | 20 |
| Gross margin ≥ 40% | 12 |
| Gross margin ≥ 25% | 6 |
| Operating margin ≥ 20% | 20 |
| Operating margin ≥ 12% | 12 |
| Operating margin ≥ 5% | 6 |
| ROE ≥ 20% | 15 |
| ROE ≥ 12% | 8 |
| Revenue growth ≥ 15% | 12 |
| Revenue growth ≥ 8% | 7 |
| Revenue growth ≥ 3% | 3 |
| FCF positive | 10 |
| Debt/Equity < 0.5× | 8 |
| Debt/Equity < 1.5× | 4 |
| ETF count ≥ 3 | 15 |
| ETF count = 2 | 10 |
| ETF count = 1 | 5 |

**Financial sector path** (FINANCIAL_SECTORS set: Financial Services, Financials, Finance, Banks, Insurance):
ROE-primary, uses P/B ratio instead of gross margin.
| Signal | Points |
|--------|--------|
| ROE ≥ 15% | 30 |
| ROE ≥ 10% | 18 |
| ROE ≥ 6% | 8 |
| P/B 1–3× (fair value) | 20 |
| P/B < 1 (below book) | 12 |
| P/B ≤ 5× | 8 |
| Revenue growth ≥ 10% | 20 |
| Revenue growth ≥ 5% | 12 |
| Revenue growth ≥ 0% | 5 |
| Net income positive | 15 |
| FCF positive | 5 |
| ETF count ≥ 3 | 10 |
| ETF count = 2 | 7 |
| ETF count = 1 | 3 |

### Beaten-Up Score (0–100)
| Signal | Points |
|--------|--------|
| 52w drawdown ≥ 30% | 30 |
| 52w drawdown ≥ 20% | 20 |
| 52w drawdown ≥ 10% | 10 |
| YTD ≤ -20% | 25 |
| YTD ≤ -10% | 15 |
| YTD ≤ -5% | 8 |
| YTD ≤ 0% | 3 |
| RSI < 30 (oversold) | 25 |
| RSI < 40 | 15 |
| RSI < 50 | 5 |
| Price below 200-day MA | 20 |

RSI: 14-day Wilder's smoothing, calculated from 1-year daily close history.
200-day MA: falls back to 50-day MA (10 pts) if fewer than 200 trading days available.

### Recovery Bonus (0–30, capped)
| Signal | Points |
|--------|--------|
| Insider buying (cross-ref InsiderBuying/data/results.json) | 15 |
| Earnings beat positive (Finnhub most recent quarter) | 10 |
| Price stabilization (30-day range < 10%) | 5 |

## Key Design Decisions

- **Financial sector separate path (Mar 2026):** Banks/insurance gross margins are meaningless. Financial sector stocks use ROE-primary quality scoring with P/B ratio and net income positive instead.
- **RSI included:** Weekly scan cadence makes the staleness concern minimal; RSI is a meaningful oversold signal.
- **Free ranking (no sector cap):** Top 10 ranked purely by composite score regardless of sector concentration.
- **Recovery bonus capped at 30 pts:** Prevents recovery signals alone from qualifying a low-quality stock.
- **Insider cross-reference:** Reads `InsiderBuying/data/results.json` locally — checks `cluster_buys`, `csuite_buys`, `big_money`, `recent_feed` arrays for ticker overlap.
- **Render URL:** `https://invest-underdogs.onrender.com` (update once deployed)
- **Port:** 8100

---

## Known Issues / Possible Improvements

- **yfinance rate limits:** Scan covers ~300-400 tickers with 0.5s sleep between each — expect 5-10 min runtime.
- **Insider data freshness:** Cross-reference uses whatever InsiderBuying last wrote to results.json — may be from earlier in the same day or last run.
- **No historical score tracking:** results.json is overwritten each scan.
- **Possible next feature:** Technical indicators (MACD, volume ratio), watchlist override.
